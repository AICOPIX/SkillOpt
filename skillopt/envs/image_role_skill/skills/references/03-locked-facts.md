# 03 Locked Facts

Locked facts 是用户明确说出的内容。优化 prompt 时必须保留。

## 必须锁定的字段

| 字段 | 例子 | 处理方式 |
|---|---|---|
| 主体 | 一只猫、现代客厅、机器人 | 保留，不替换 |
| 数量 | 一只、两个人、三张卡片 | 保留，不增减 |
| 风格 | 水彩、3D、电影感、SU 风格 | 保留，不冲突 |
| 颜色 | 红色、黑白、蓝紫渐变 | 保留 |
| 材质 | 金属、玻璃、木头、陶瓷 | 保留并细化 |
| 时间 | 夜晚、清晨、黄昏 | 保留并补光照 |
| 地点 | 城市屋顶、窗边、客厅 | 保留并补环境 |
| 关系 | 大战、拥抱、并排、坐在 | 保留并强化动作 |
| 精确文字 | “ARVUNE” | 加引号，不改写 |
| 排除项 | 不要人物、不要文字 | 保留到最终 prompt |
| 比例尺寸 | 16:9、竖版、1:1 | 放在 prompt 前部 |

## 允许增强的内容

- 镜头
- 光照
- 构图
- 质感
- 背景
- 细节
- 氛围
- 空间层次
- 输出质量

## 不允许的修改

用户说“一只猫”，不能改成“两只猫”。

用户说“现代客厅”，不能改成“欧式古典客厅”。

用户说“标题是 ARVUNE”，不能改成“ARVUNE AI Studio”。

用户说“不要人物”，不能添加人物剪影或模特。

用户说“水彩风”，不能改成写实摄影，除非用户要求多版本。
