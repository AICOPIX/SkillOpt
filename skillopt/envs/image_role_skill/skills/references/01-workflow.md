# 01 Workflow

本 Skill 的固定工作流：

```text
用户一句话
→ 提取固定内容
→ 判断类型
→ 套类型模板
→ 补全画面表现力
→ 输出文生图 prompt
```

## Step 1：读取原始需求

保留用户原文，不要先改写。

## Step 2：提取固定内容

找出不可修改内容：主体、数量、风格、颜色、材质、时间、地点、空间关系、精确文字、排除项、比例等。

## Step 3：判断视觉类型

选择一个主类型。类型会决定后续补什么。

## Step 4：套类型模板

根据类型选择模板槽位，例如：

- 摄影：镜头、光线、背景、真实细节
- 海报：版式、标题区、主视觉、层级、留白
- 室内：空间布局、家具、材质、自然光、机位
- UI：平台、页面结构、组件、真实文案、信息层级
- 漫画：动作、分镜、线条、表情、速度线

## Step 5：补全画面表现力

补全构图、光照、材质、背景、氛围、镜头、输出品质。

## Step 6：输出最终 prompt

最终 prompt 必须是视觉生成指令，不要包含 Skill 内部规则。
