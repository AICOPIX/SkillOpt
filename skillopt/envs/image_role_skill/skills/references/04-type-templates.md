# 04 Type Templates

以下模板用于把短 prompt 扩展成类型化文生图 prompt。

## photography_life_scene 模板

```text
[主体]位于[具体场景]中，[动作/状态]，[光线描述]，[镜头/机位]，[背景处理]，[材质/细节]，[情绪氛围]，真实摄影风格，[输出质量]。
```

## cinematic_scene 模板

```text
[主体A]与[主体B/环境冲突]在[时间/地点]中[动作关系]，[镜头角度]，[前景/中景/背景层次]，[戏剧化光影]，[运动细节]，[天气/粒子/烟雾/火花]，电影级画面，强烈叙事张力。
```

## poster_design 模板

```text
[比例/画布]海报设计，主题为[主题]。主视觉：[主体]；版式：[布局方式]；标题区：[标题文案，如有]；副标题/信息区：[信息，如有]；色彩：[主色/辅色]；风格：[风格]；氛围：[情绪]；要求文字清晰、层级明确、留白合理、适合传播。
```

## typography_poster 模板

```text
[比例]概念字体海报，准确显示标题“[精确标题]”。标题是画面主视觉，字体具有[字重/结构/材质/情绪]，配合[隐喻元素/背景]，强层级、克制配色、清晰可读，不添加无关大段文字。
```

## product_render 模板

```text
[产品]商业主视觉渲染，[展示角度]，[材质细节]，[棚拍光/边缘光/反射]，[背景/台面]，[辅助元素如用户允许]，主体突出，干净高级，商业摄影质感，细节清晰。
```

## ecommerce_visual 模板

```text
[比例]电商商品视觉，[商品]作为画面中心，[卖点模块/标签区]，[干净背景]，[少量辅助道具]，[光照和材质]，信息清楚，商品识别强，避免杂乱。
```

## interior_design 模板

```text
[空间类型]室内设计，[风格]，[空间布局]，[主要家具]，[材质组合]，[色彩系统]，[光线来源]，[机位/镜头]，空间通透，真实阴影，材质细节清晰，室内摄影效果。
```

## architecture_render 模板

```text
[建筑类型]建筑效果图，[视角]，[体块关系]，[立面材料]，[场地/景观关系]，[日照/天气]，[尺度参考]，建筑可视化风格，透视准确，空间关系清楚。
```

## sketchup_style_render 模板

```text
[建筑/空间对象]的 SketchUp 风格建筑表现图，清晰体块，简洁边线，块面材质，柔和阴影，建筑汇报图感觉，干净背景，避免过度写实和杂乱贴图。
```

## ui_design 模板

```text
[平台/设备] UI 界面设计，产品为[产品/功能]，页面结构包括[导航/标题区/卡片/按钮/图表/列表]，主色[颜色]，风格[风格]，真实可读文案，信息层级清楚，间距精确，高保真产品界面截图。
```

## web_design 模板

```text
[网站类型]网页设计，[画布比例/屏幕]，顶部导航，Hero 区包含[标题/副标题/CTA]，中部模块包含[功能/卡片/图表/展示]，风格[风格]，配色[配色]，现代网页排版，层级清晰，可读性强。
```

## infographic 模板

```text
[比例]信息图，主题为[主题]，结构为标题区 + [3-5]个模块，每个模块包含短标题、图标/小插图、1句简短说明，使用清晰箭头/连线/色块表示关系，信息层级清楚，避免长段文字。
```

## comic_manga 模板

```text
[漫画/分镜]画面，[角色/主体]正在[动作]，[场景]，[镜头角度]，[线条/网点/上色风格]，[速度线/拟声词如用户允许]，[表情和动作张力]，叙事清晰，画面有冲突和节奏。
```

## illustration_art 模板

```text
[主体]插画，[画材/风格]，[构图]，[色板]，[笔触/线条]，[背景装饰]，[情绪氛围]，层次丰富但画面干净。
```

## character_design 模板

```text
[角色]角色设计，[身份/性格锚点]，[服装]，[发型/面部特征]，[姿态]，[配饰]，[配色]，[风格]，轮廓清晰，识别度强，设定统一。
```

## game_concept 模板

```text
[游戏类型/场景]概念图，[角色/场景/道具]，[视角]，[环境叙事细节]，[UI/HUD 如需要]，[光照和色彩]，游戏截图或概念设定风格，可玩性和世界观明确。
```

## three_d_model_render 模板

```text
[主体]3D 模型渲染，[展示角度]，[材质]，[灯光]，[底座/背景]，[细节精度]，干净工作室背景，模型边缘清晰，高质量渲染，适合作品集展示。
```

## logo_concept 模板

```text
[品牌/概念]Logo 概念设计，[符号逻辑]，[几何/字体/负空间]，[配色]，简洁、高识别度、可缩放，避免复杂插画和随机装饰。
```

## brand_visual 模板

```text
[品牌名/主题]品牌视觉板，包含 Logo 区、色板、字体系统、包装/名片/社媒样机等触点，统一视觉规则，排列整齐，品牌识别清楚。
```

## document_layout 模板

```text
[文档类型]页面设计，[页面比例/尺寸]，标题区、正文分栏、图表/插图模块、注释区，字体层级清楚，留白合理，出版物级排版，文字短而可读。
```
