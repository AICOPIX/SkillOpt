# 05 Prompt Craft

## 1. 不要原样复读

弱：

```text
一只猫
```

强：

```text
一只猫安静地坐在窗边，柔和自然光从侧面照入，毛发细节清晰，浅景深，背景是温暖简洁的室内生活场景，真实摄影风格。
```

## 2. 类型决定补全方向

“现代客厅”要补室内设计语言，不要补电影战斗语言。

“科技海报”要补版式、主视觉、标题区、色彩、层级。

“网页设计”要补导航、Hero 区、CTA、卡片、组件。

## 3. 固定内容优先

用户明确说出的主体、数量、文字、排除项优先级最高。

## 4. 具体名词比空泛形容词更有用

少写：

```text
高级、漂亮、震撼、专业
```

多写：

```text
落地窗、浅灰布艺沙发、木地板、暖白墙面、自然光、黑色细腿茶几
```

## 5. 材质、光照、色彩分开写

不要只写“高级质感”。

应该拆成：

```text
材质：拉丝金属、磨砂玻璃、浅木纹
光照：柔和侧光、边缘光、自然漫射光
色彩：米白、浅灰、原木色
```

## 6. 精确文字必须加引号

如果用户要求画面里出现文字，必须保留原文并加引号。

例如：

```text
标题准确显示“ARVUNE”
```

不要改写为：

```text
标题是 ARVUNE AI
```

## 7. 比例和布局要靠前

海报、UI、网页、信息图、PPT 这类结构化画面，先写比例和布局，再写细节。

## 8. 负面约束短而精准

不要默认加一长串“不要”。

只有以下情况加：

- 用户明确说不要
- 该类型有高概率错误
- 文字 / logo / 人物 / 杂乱背景会破坏结果

## 9. 不把内部规则塞进最终 prompt

不要在最终 prompt 里写：

```text
保留用户明确描述的主体、数量、风格……
```

这类内容是 Skill 内部规则，不是画面内容。
